# ⚖️ Legal Bot 2026 - Frontend Interface

المساعد القانوني الذكي للتشريعات والقوانين الأردنية — مشروع تخرج قسم نظم المعلومات الحاسوبية (CIS) في جامعة آل البيت.

## 🚀 نبذة عن المشروع
منصة ذكاء اصطناعي تفاعلية مصممة للمحامين والمتدربين والعملاء لتسهيل الاستشارات القانونية وتحليل اللوائح والقضايا بناءً على التشريعات الأردنية باستخدام تقنيات RAG (Retrieval-Augmented Generation).

## 🛠️ التقنيات المستخدمة (Tech Stack)
- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS & Lucide Icons
- **Theme:** Dark Luxury Legal Design (Glassmorphism & Stone-950)
- **Language:** JavaScript (React)
